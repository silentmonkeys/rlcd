# rlcd_debug_gui —— RLCD 模拟器图形化调试客户端

通过 TCP 连接模拟器（默认 `127.0.0.1:9000`，与 `rlcd_debug` 同一协议），
用**滑块 / 输入框 / 按钮**远程读写 `ui_model` 字段、切页、标注日历。

> 解决原方案"开两个终端太麻烦"的问题：**一个 GUI 窗口完成全部调试**，
> 模拟器端零改动（复用 `sim_console` + TCP server）。

## 依赖

仅 Python 3.8+ 标准库（`tkinter` + `socket` + `threading`），无需 `pip install`。

## 用法

```sh
# 终端 1：启动模拟器（带 TCP debug server）
cd simulator && cmake -B build && cmake --build build -j
./build/rlcd_sim

# 终端 2：启动图形化调试客户端
python3 tools/rlcd_debug_gui/rlcd_debug_gui.py
```

启动后在 GUI 里填地址端口 → 点 **连接** → 即可调试。

## 字段类型

- **Spinbox（数字输入框）**：数值（温度/湿度/风速/电量 …），可键盘直输精确值，回车或点「设置」发送
- **下拉框**：天气代码（和风天气 icon 代码 + 中文描述），**选中不即发**，必须点「设置」才发送（与其他字段行为一致）
- **复选框**：布尔（WiFi 连接 / 充电中），切换即发送
- **文本框**：字符串（城市名 / 天气文本 / 风向 / 日出日落），回车或点「设置」发送

## 读取全部

顶部「读取全部」按钮一键 `get` 全部 22 个字段，方便连接后一次性看全状态。

## 连接说明

采用**持久 TCP 连接**：点「连接」后连一次，全部命令复用同一条连接。
服务端只打印一次 `client connected`，直到点「断开」或关闭窗口才断开 ——
不会出现"每操作一次就 connected/disconnected"的闪断现象。

## 协议速查

```
set <field> <value>      写字段（override 保留）
get <field>              读字段
page N / next / prev     切页
mark MM-DD / unmark      日历标注
marks MM-DD,MM-DD,...   批量标注
clear                    清除 override，恢复模拟器自动填充
ping / quit
```

完整字段列表见 `rlcd_debug_gui.py` 的 `FIELD_GROUPS`。
